# MARK-XL Branding

## Name

**MARK-XL**

Use `MARK-XL` for the project/repository name and `JARVIS` for the assistant persona inside the runtime.

Avoid mixing older names such as `MARK XLI`, `MARK-XXXIX`, or fork-origin names in public-facing copy unless referencing project history.

## Positioning

MARK-XL is a local-first personal AI command system for Windows. It is not just a chatbot: it is a tool-running desktop assistant with voice, vision, memory, automation, maps, weather, media, games, and Obsidian knowledge.

## Short Descriptions

- Local-first Jarvis-style AI for PC automation, vision, voice, and Obsidian memory.
- Personal command OS for Windows: voice, vision, maps, weather, media, games, and local brain.
- MARK-XL turns natural language into useful PC actions.

## Taglines

- `Local brain. Real actions.`
- `Voice, vision, memory, control.`
- `Your PC, operated by intent.`
- `A Jarvis-style command layer for Windows.`

## Tone

- Direct, technical, useful.
- Assistant should sound calm and operational, not like marketing copy.
- Prefer concrete capability statements over hype.
- Be explicit when a function depends on local setup, credentials, or external apps.

## Visual Direction

Recommended style:

- Dark operational interface.
- Accent colors: electric cyan, violet, and signal green.
- Avoid one-color purple-only themes.
- Dense dashboards are preferred over marketing landing pages.
- Use technical panels, maps, graphs, waveforms, and status indicators.

Suggested palette:

| Token | Hex | Use |
|---|---:|---|
| Background | `#090B10` | Main dark surface |
| Panel | `#121722` | HUD panels |
| Text | `#E8EDF7` | Primary text |
| Muted text | `#8D97AA` | Secondary text |
| Cyan | `#32D9FF` | Active voice/vision accent |
| Violet | `#8B5CF6` | Neural/brain accent |
| Green | `#49E68A` | Success/online states |
| Amber | `#F7B84B` | Warning states |
| Red | `#FF5C7A` | Error/blocked states |

## Privacy Statement

MARK-XL is designed as a personal system. Public repositories should not include:

- API keys or tokens.
- Personal memory JSON files.
- Generated Obsidian indices containing private note titles/content.
- Face recognition data.
- Sound samples.
- Screenshots or camera captures.
- Device-specific config files.
