# Branding do MARK-XL

## Nome

**MARK-XL**

Use `MARK-XL` como nome do projeto/repositório e `JARVIS` como persona do assistente dentro do runtime.

Evite misturar nomes antigos como `MARK XLI`, `MARK-XXXIX` ou nomes do fork original em textos públicos, exceto ao falar do histórico do projeto.

## Posicionamento

MARK-XL é um sistema pessoal de IA local-first para Windows. Ele não é apenas um chatbot: é uma camada de comando para PC com voz, visão, memória, automação, mapas, clima, mídia, jogos e conhecimento Obsidian.

## Descrições Curtas

- IA pessoal estilo Jarvis para automação do PC, visão, voz e memória Obsidian.
- Sistema pessoal de comando para Windows: voz, visão, mapas, clima, mídia, jogos e cérebro local.
- MARK-XL transforma linguagem natural em ações úteis no PC.

## Taglines

- `Cérebro local. Ações reais.`
- `Voz, visão, memória e controle.`
- `Seu PC operado por intenção.`
- `Uma camada de comando estilo Jarvis para Windows.`

## Tom

- Direto, técnico e útil.
- O assistente deve soar calmo e operacional.
- Prefira capacidades concretas a hype.
- Seja explícito quando uma função depender de configuração local, credenciais ou apps externos.

## Direção Visual

Estilo recomendado:

- Interface operacional escura.
- Cores de destaque: ciano elétrico, violeta e verde de sinal.
- Evitar telas dominadas por um único roxo.
- Dashboards densos são melhores do que páginas estilo marketing.
- Usar painéis técnicos, mapas, gráficos, waveforms e indicadores de status.

## Privacidade

O MARK-XL é um sistema pessoal. Repositórios públicos não devem incluir:

- Chaves de API ou tokens.
- JSONs de memória pessoal.
- Índices gerados do Obsidian com títulos/conteúdos privados.
- Dados faciais.
- Amostras de som.
- Screenshots ou capturas de câmera.
- Configurações específicas de dispositivos.
